这里仅存放面向用户、经过公开发布审查的文档。内部实施计划、运行记录和环境配置应保存在仓库外的私有目录；需要协作时使用单独的私有仓库，并核对其可见性与访问成员。密码和 API 密钥使用密钥管理工具，不放入文档或 Git。

提交文档前检查其中的真实用户数据、主机地址、个人路径、账号权限和日志；示例使用合成数据与占位符。新增公开文档时，单独审查内容及链接，再更新本仓库的文档允许列表，勿以强制添加绕过审查。删除当前文件不会清除已发布的 Git 历史。

This directory contains reviewed user documentation. Keep internal plans, run logs, and environment notes outside the public checkout; use a separate private repository with verified access for collaboration. Store credentials in a secret manager. Review new public documents and links before updating the documentation allowlist. Deleting files does not erase published Git history.
